# Amazon S3 Infrastructure Documentation

S3 bucket `loanpred-mlops-20251118-120330` stores MLflow artifacts, DVC datasets, and model registry.

## Structure
- mlruns/ - MLflow tracking and models
- .dvc/ - DVC dataset cache
- datadrift/ - Evidently AI reports

## Configuration
- Region: eu-west-2
- Encryption: SSE-S3
- Versioning: Enabled

## Usage
At container startup, `start.sh` syncs `mlruns/` from `S3_BUCKET` into the image and the app serves models via a local file-based `MLFLOW_TRACKING_URI` (`file:/app/mlruns`).
